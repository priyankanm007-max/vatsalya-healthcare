# Vatsalya Rural Telemedicine

Smart telemedicine application for rural healthcare access. Vatsalya connects rural patients with qualified doctors through live doctor availability, appointment scheduling, online consultation actions, digital prescriptions, multilingual UI, low-data design, and emergency healthcare alerts.

## Features

- Patient login and signup
- Doctor login and signup
- Doctor availability display
- Appointment booking
- Telemedicine consultation support
- Digital prescription upload and storage
- AI symptom guidance
- Emergency SOS support
- Clean and simple rural-friendly UI

## Tech Stack

Frontend:
- React
- Vite
- Tailwind CSS

Backend:
- Node.js
- Express.js

Database:
- MongoDB

File Upload:
- Multer
